Скалярный loss F(θ) — что минимизирует GA (чем меньше, тем лучше)

      

        F(θ) = wn·ln(1+n/n0) + wpos·ln(1+(pos/tol)²) + wwell·ln(1+(well/tol)²) + wlag·ln(1+(lag/dist)²)

             + 0.5·ln(1+max(0,rms−0.1)/0.1) — искажение ЦАП

             + λ·mean(((θ−θc)/scale)²) — штраф управления (θ в границах)

             + 2·ln(1+max(0,f0−fmin)/1e5) + fmax + нач/кон — гейты: min f, max f (1e5), начальная/конечная частота (0.05МГц, порог 0.02МГц)

             + robust: 0.35·mean+0.65·max − primary — только R: доплата = агрегация − обычный loss

             + 2·ln(1+max(0,hr−allowed)/max(allowed,50)) — нагрев (только если max_heating_rate_hz задан, порог 1.05·allowed)

             + 2·ln(1+dist/1мкм) — высота: dist=выход ямы за [height_min, height_max], 1 мкм масштаб
        

          Обозначения: n — ntotal фононов (цель <0.5), pos — ошибка позиции |<r>−target| (цель <tol), well — ошибка минимума ямы, lag — max|ион−яма| по траектории, rms — искажение DAC (>0.1В штрафуется), fmin — минимальная секулярная частота (цель ≥f0), λ=1e-4, n0=task.max_n_total, tol=position_tolerance_m, dist=distance_m.

           · веса wn/wpos/wwell/wlag из loss_weights (по умолчанию 1/1/1/0) — меняются в конфиге

n_total фононы
ln(1+n/n0). n0=0.5. Если n=0.1 → 0.18, n=1 → 1.1. Цель ≤0.3

        
pos ошибка
ln(1+(pos/tol)²). tol=5мкм. pos=1мкм→0.04, 10мкм→1.6. Должно →0

        
well яма
аналогично pos, но для минимума потенциала. →0

        
lag отставание
max|ион−яма|/dist. Обычно выкл (w_lag=0). Если вкл — штраф за отставание

        
distortion
rms искажения >0.1В. rms=0.12→0.09, 0.3→0.55

        
control
θ близко к границам. Обычно <0.05

        
freq gate
если fmin<f0: 2·ln(1+Δ/1e5). Провал на 200кГц→2.2

        
heating
2·ln(1+(hr−allowed)/max(allowed,50)), если hr>1.05·allowed и max_heating_rate_hz задан

        
height
яма вне высоты → 2·ln(1+dist/1мкм)

        
corridor
коридор > halfwidth → 2·ln(1+Δ/1мкм)

        
robust
только R: 0.35·mean+0.65·max − primary. Показывает неустойчивость
