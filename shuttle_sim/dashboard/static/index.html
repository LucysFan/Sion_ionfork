Как это работает всегда видно, даже без запусков

    

      1. Загружаешь GDS — просто кинь файл сюда (или выбери из configs/*.gds).

      2. Ставишь расстояние и время — например 100 мкм за 20 мкс для большой ловушки.

      3. Жмёшь «GA робаст + дашборд» — острова S/A/V/R/H начнут эволюцию, дашборд сразу показывает Training (красивые графики), GA (миграции, диверсити) и Trap (яма + ион, анимация 60fps).

      Робастность: остров R оптимизирует 0.35*mean + 0.65*worst по 3 train-сценариям (gain/offset/delay/filter/stray) — выживают не быстрые, а устойчивые.

      Вкладки всегда доступны: даже пока ничего не запущено — видишь предыдущие output/* прогоны, можешь переключать .

      
Текущий общий файл: configs/unified_live.json — это твой «один файл» для ловушки. Меняешь в Setup → Сохранить → Запустить — всё через него. Хардвер (DAC 20MS/s, RC 1МГц+500кГц, jitter per-sample) уже внутри.
